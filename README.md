# Nuzlocke Everywhere

Downloads of Nuzlocke Everywhere, an app that adds Nuzlocke rules, level caps and helpers to Pokémon games running in BizHawk.

Get **Nuzlocke Everywhere.exe** from [the latest release](https://github.com/MewzaH/nuzlocke-everywhere-releases/releases/latest) and open it: it needs no install. Each time it opens it checks this page, and offers a newer version when there is one.

No ROMs, BIOS files or game art are included or ever downloaded: you play your own games.
